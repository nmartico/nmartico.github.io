Section 6: Creating a more advanced graph using vega-lite and data from World Bank API

In this case, we are using the World Bank API for obtainning the data. Search for “World Bank API indicators documentation” on Google and open the first result. Then, use the example link and experiment with it. It is necessary to change the output format to JSON (?format=json) after installing the JSON Viewer extension for Mozilla Firefox. Experiment with different countries (KOR; JPN; CHN; COL) and explore the many available options (see the World Bank API guide). You can, for example, retrieve data for the last ten years available. All these experiments are being tested in Vega Lite, with the output chart. So, any changes in the graph should be done in the VegaLite website (and at the end just export the chart to json and upload it in our project). This is great because we don't have to worry about downloading and uploading a data file, and the data will update automatically whenever the source is updated. Buuuut, we do need to keep an eye out for any changes to the API.
